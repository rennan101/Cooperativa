# Sprint 01 - Fundação, Design System e Layouts

**Objetivo da Sprint**: Estabelecer a infraestrutura de front-end, definir o design system inspirado no BlaBlaCar e estruturar os layouts base da aplicação.

---

## Tarefas de Desenvolvimento

1. **Setup & Configuração Base**:
   - Inicialização do projeto (React/Next.js + TypeScript).
   - Configuração do Tailwind CSS com tokens BlaBlaCar (cores `#00AFF5`, `#054752`, `#00A651` descritas em [[Design_System_BlaBlaCar]]).
   - Configuração de bibliotecas de ícones (Lucide React) e gerenciamento de estado (Zustand).

2. **Desenvolvimento de Componentes Base (UI Kit)**:
   - Botões com variantes (Primary, Secondary, Ghost, Danger).
   - Inputs, dropdowns, badges e modais acessíveis.
   - Stepper / Linha do tempo de rotas.

3. **Layouts Estruturais**:
   - Cabeçalho global responsivo com navegação contextual por perfil ([[MOC_Perfis_Permissoes]]).
   - Rodapé informativo e container de visualização responsiva (mobile-first).

---

## Critérios de Aceite
- [ ] Cores e tipografia idênticas ao guia [[Design_System_BlaBlaCar]].
- [ ] Componentes base testados em desktop e mobile.
- [ ] Estrutura de roteamento inicial funcionando.
