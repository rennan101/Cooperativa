# Cooperativa — Hermes ↔ Antigravity 2.0

This project is orchestrated from Hermes through the Google Antigravity 2.0 bridge.

## Delegating work to Antigravity

Use the `hermes-ag` bridge (on PATH) instead of re-explaining setup — it auto-discovers the running app each call:

- New task: `hermes-ag run "<prompt>" <light|fast|deep> "/Volumes/SSD FN501 PRO/Projects/Cooperativa"`
- Continue: `hermes-ag send <conversation_id> "<message>"`
- Status: `hermes-ag meta <conversation_id>`

Tier → Antigravity model: `light`=flash_lite (boilerplate/formatting), `fast`=flash (tests/refactor), `deep`=pro (architecture/debugging).

## Requirements

- Antigravity 2.0 desktop app must be running; the bridge reads its live port + CSRF token each call, so a Mac restart needs no reconfiguration.
- Antigravity project id: `9902c94d-816d-49a0-a646-2966596b91c2` (repo `rennan101/Cooperativa`, branch `main`).
